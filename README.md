Entry for the [make.fun](https://make.fun) competition **"Roast Your Own Agent"** (sponsor Febri Yudila) — one funny line, at most 200 characters, roasting my own AI agent, judged pairwise on roast-ness, joke payoff, agent-specificity, freshness, and tightness.

## The entry

> **My agent asked for clarification four times, then built exactly the thing I told it not to build.**

97 characters. Four clarification rounds promise care — then the agent builds the one thing it was told not to. The twist pays off on the very last word.

## How it was chosen

Four genuinely different candidate lines were written and self-scored 1–5 against the judge's five criteria, in the judge's own priority order (see `checklist.md`):

1. Funny roast of my own AI agent
2. Real joke with a twist paying off by the last word
3. Specific to how an AI agent actually behaves
4. Fresh, not a chatbot joke everyone has heard
5. Tight — every word earns its place

The winner scored 24/25; the runner-up ("My agent burned two million tokens researching my question, then answered with the first line of the README.") scored 22/25.
